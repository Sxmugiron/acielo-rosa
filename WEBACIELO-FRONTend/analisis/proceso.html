PROCESAMIENTO DE DATOS

¿Cómo funciona Apache Spark?

Conoce el proceso utilizado para transformar un conjunto de datos de citas médicas en estadísticas y visualizaciones.

Dashboard Proceso Arquitectura Metodología

¿Qué es Apache Spark?

Apache Spark es un motor de procesamiento de datos que permite realizar operaciones sobre conjuntos de información mediante un sistema de ejecución distribuida.

En WEBACIELO se utiliza para analizar un dataset público de citas médicas, calcular indicadores y producir resultados que pueden visualizarse desde el navegador.

Etapas del procesamiento

01

Obtención del dataset

Se utiliza el conjunto de datos público Medical Appointment No Shows, disponible en Kaggle, con registros de citas médicas.

02

Lectura con Spark

El archivo CSV se procesa mediante Apache Spark. Los registros se representan en estructuras que permiten consultar y transformar sus columnas.

03

Preparación de la información

Se interpretan las variables relevantes, como asistencia, edad, recordatorios SMS y fecha de las citas, para preparar los análisis.

04

Cálculo de indicadores

Spark permite agrupar registros y obtener cantidades, distribuciones y porcentajes relacionados con la asistencia a las citas.

05

Generación de resultados

Los resultados del procesamiento se preparan para su consulta mediante archivos de datos y representaciones gráficas.

06

Visualización web

El frontend solicita los indicadores y las gráficas a una API y los presenta en el dashboard de WEBACIELO.

Flujo general de la información
