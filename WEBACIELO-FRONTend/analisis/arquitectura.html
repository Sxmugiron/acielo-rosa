Distribución de componentes

01

Ubuntu1: interfaz web

Aloja las páginas HTML, CSS y JavaScript. El navegador consulta la API de análisis para mostrar las estadísticas.

02

Ubuntu2: procesamiento

Aloja Apache Spark y los componentes encargados de generar y exponer los resultados del análisis de citas médicas.

03

Spark Master

Coordina la ejecución de tareas del entorno Spark. En este proyecto, se ejecuta en Ubuntu2.

04

Spark Worker

Ejecuta las tareas de procesamiento asignadas por Spark. En esta implementación, Master y Worker están alojados en la misma máquina virtual.

¿Por qué se utiliza una API?

La API funciona como intermediaria entre los resultados generados en Ubuntu2 y la interfaz web que se visualiza desde Ubuntu1.

Esto permite separar la presentación de los datos de su procesamiento. El navegador no necesita ejecutar Apache Spark para consultar las estadísticas.
